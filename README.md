# Naman Portfolio

A personal portfolio built with Next.js and Tailwind CSS.

## Quick Start

1. Install Node.js 20 or newer.
2. Install dependencies:
	 corepack pnpm install
3. Start the dev server:
	 corepack pnpm dev
4. Open http://localhost:3000

## Available Scripts

- corepack pnpm dev: Starts the stable dev server (default).
- corepack pnpm dev:turbo: Starts Turbopack mode.
- corepack pnpm build: Creates production build.
- corepack pnpm start: Runs production build.
- corepack pnpm lint: Runs lint checks.

## Troubleshooting

- pnpm is not recognized:
	Use Corepack commands shown above instead of plain pnpm.

- Port 3000 already in use:
	Stop old terminal sessions running Next.js, or use the URL shown in terminal (for example http://localhost:3001).

- Module not found warnings in editor:
	Run corepack pnpm install, then reload VS Code window if needed.
